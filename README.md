# Clojure Full-Stack Todo App

Projeto full-stack desenvolvido em Clojure e ClojureScript.

## 🧱 Arquitetura e Tecnologias

- **Backend**: Clojure, Ring, Reitit e next.jdbc
- **Frontend**: ClojureScript com Reagent 2.0 (React 19) e Shadow-CLJS
- **Banco de Dados**: SQLite para persistência real

## 📋 Jornada Incremental

1. **Fundação**: Verificação do ambiente, Git e `.gitignore`
2. **Backend mínimo**: Servidor "Hello World" com Jetty e Reitit
3. **Banco em memória**: Criando e lendo tarefas com atom
4. **Frontend reativo isolado**: Interface dinâmica com Reagent
5. **Integração full-stack**: Comunicação via API REST e CORS
6. **Banco real**: Migração para persistência SQLite com next.jdbc
7. **CRUD completo**: Atualização e remoção de tarefas
8. **Documentação**: README profissional e preparação para entrega
